# Mafi.AI

This repository displays the backend-code for the game-logic of Mafia.AI. It is designed to be containerised with Dockerfile.game and deployed with AWS. This is a showcase of my skills as a developer.

## What is Mafi.AI?

Mafi.AI is an online game inspired from the party game Mafia (A.K.A. Werewolf). However, in this version, you play against the AI. Play against the latest GPT models (Soon to include Claude/Gemini models) AND your friends in real time.
